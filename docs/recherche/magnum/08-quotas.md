# Quota Magnum de clusters par projet

Le seul type de ressource du quota Magnum dans cette série est `Cluster`. Un quota de cinq clusters ne fixe ni le nombre de pools ni le nombre de VM par pool. Pour ajouter des workers, Skyline doit distinguer les ressources consommées dans Nova et, selon le modèle, Cinder. [Types Magnum](https://opendev.org/openstack/magnum/src/commit/68befbf84e8ec50e57dee682cea9398bba606904/magnum/objects/fields.py) · [Quota dans le formulaire de création Skyline](https://github.com/armeldemarsac92/skyline-console/blob/5a8ca40e86cbcbacf725b38fc14ca5acbed1e19a/src/pages/container-infra/containers/Clusters/actions/StepCreate/index.jsx)

| Commande après `openstack coe` | Requête Magnum | Ce que propose le fork |
|---|---|---|
| `quotas show --project-id PROJET --resource Cluster` | `GET /v1/quotas/{project_id}/Cluster` | Le récapitulatif de quotas et le formulaire de création utilisent la limite du projet. |
| `quotas create` / `quotas update` | `POST /v1/quotas` / `PATCH /v1/quotas/{project_id}/Cluster` | « Gérer les quotas » réunit les deux actions. Le store crée une entrée si aucun ID de quota explicite n’est connu, sinon il la modifie. Le corps contient notamment `hard_limit`. |
| `quotas list [--all-tenants]` | `GET /v1/quotas` | Aucun écran dédié à la liste des dérogations Magnum entre projets. |
| `quotas delete --project-id PROJET --resource Cluster` | `DELETE /v1/quotas/{project_id}/Cluster` | Aucune action dédiée pour revenir à la valeur par défaut. |

La règle par défaut permet au lecteur du projet de consulter sa limite. Créer, modifier, lister les entrées et les supprimer relève de l’administration. Supprimer une entrée explicite fait réapparaître la valeur configurée `quotas.max_clusters_per_project` à la prochaine lecture. Mettre `hard_limit` à zéro enregistrerait au contraire une limite explicite de zéro. [API et valeur par défaut](https://opendev.org/openstack/magnum/src/commit/68befbf84e8ec50e57dee682cea9398bba606904/magnum/api/controllers/v1/quota.py) · [Politiques](https://opendev.org/openstack/magnum/src/commit/68befbf84e8ec50e57dee682cea9398bba606904/magnum/common/policies/quota.py) · [Documentation CLI 2026.2](https://docs.openstack.org/python-openstackclient/2026.2/cli/plugin-commands/magnum.html#coe-quotas-show)

Skyline calcule la consommation présentée en comptant les clusters renvoyés par `clusters.listDetail()`. Seule la première réponse est comptée et l’appel n’indique pas le projet sélectionné. En administration, la limite affichée peut donc concerner le projet choisi alors que la consommation inclut des clusters d’autres projets. Pour un compteur ciblé, Magnum accepte `GET /v1/stats?project_id={project_id}`.
