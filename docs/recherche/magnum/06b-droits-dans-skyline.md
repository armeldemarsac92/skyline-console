# Présenter les actions autorisées dans Skyline

Les règles par défaut distinguent la lecture du projet, les mutations par un membre et certaines opérations administratives. Dans Skyline, `policyMap.magnum` associe seulement `cluster:` et `clustertemplate:` à Magnum. Avec une liste de politiques chargée, `checkPolicyRule` renvoie `true` quand une règle recherchée est absente. Pour proposer « Créer un groupe », vérifier que la règle évaluée est bien `magnum:nodegroup:create` et disponible via Skyline. Une réponse 403 du service doit rester visible même si l’interface avait présenté l’action.
